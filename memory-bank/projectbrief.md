# Project Brief - Cigar Buddy

## Core Mission
Build an App Store-compliant iOS/Web app for cigar enthusiasts that provides identification, journaling, and pairing suggestions without facilitating tobacco sales.

## Key Requirements
- **App Store Compliance**: Age gate (21+), no tobacco sales, external purchase links only
- **Core Features**: Photo identification, journal logging, pairing suggestions, affiliate monetization
- **Target Users**: Cigar hobbyists age 21+ in US/Europe/Middle East
- **Monetization**: Ads (non-tobacco), affiliate links, premium subscription

## Success Criteria
- App Store approval and launch
- Core MVP with photo ID and journaling
- Compliant monetization model
- Low operating costs through optimized LLM/image processing

## Critical Constraints
- No in-app tobacco purchases
- All buy links open external Safari
- Age verification required
- No tobacco/alcohol ads
- Educational/neutral language only
