# Product Context - Cigar Buddy

## Problem Statement
Cigar enthusiasts lack a comprehensive digital companion for:
- Identifying cigars from photos
- Tracking their smoking experiences
- Getting pairing recommendations
- Maintaining a searchable journal

## Solution Overview
A mobile-first app that serves as a "Vivino for cigars" - providing identification, journaling, and discovery while maintaining strict App Store compliance.

## User Journey
1. **Onboarding**: Age verification (21+) → Account creation
2. **Discovery**: Photo cigar band → AI identification → View details & pairings
3. **Experience**: Log smoking session (time, place, companions, rating, notes)
4. **Reflection**: Browse journal, search entries, export data
5. **Purchase**: View retailer links (external Safari only)

## Value Propositions
- **For Hobbyists**: Digital cigar diary with AI-powered identification
- **For Collectors**: Searchable database of personal experiences
- **For Explorers**: Pairing suggestions and discovery features
- **For Business**: Compliant monetization through ads and affiliate links

## Key Differentiators
- App Store compliant (no tobacco sales)
- Photo-based identification
- Private, searchable journaling
- AI-powered pairing suggestions
- Educational focus vs. promotional
